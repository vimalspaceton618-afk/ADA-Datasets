# ADA Curator v0.4 implementation report

Snapshot as of 2026-11-26 UTC. ADA Curator v0.4 and the companion ADA trainer are open as linked draft pull requests. GitHub Actions passed on both implementation commits. [ADA-Datasets #5](https://github.com/vimalspaceton618-afk/ADA-Datasets/pull/5) · [ADA #13](https://github.com/vimalspaceton618-afk/ADA/pull/13)

## Delivered

| Area | Implementation |
| --- | --- |
| Intake | SHA-256-pinned English, Tamil and Hindi JSONL, reviewed source rights, opt-outs, multilingual privacy checks, benchmark filtering, and optional pinned fastText models. |
| Curation | Resumable Linux worker tasks, corpus-wide exact and candidate-based near deduplication, family-aware splits, and train-only token budgets. |
| Release | Typed Parquet documents and masked token blocks, a pinned tokenizer, a dataset card, and checksummed provenance and audit artifacts. |
| Governance | A private release registry, quarantine of affected releases and registered checkpoints, and verified successors with shard impact reports. |
| ADA handoff | Manifest-pinned pretraining, saved shard and row-group cursors, active-target accounting, and explicit held-out test evaluation. |

## Open validation
